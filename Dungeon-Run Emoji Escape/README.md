This game was developed for the Excode Video Game Coding Quest, and is fully playable in Google Colab, VS Code, or any local Python environment.
Game Overview

You are a brave adventurer 🧙‍♂️ trapped in a mysterious emoji dungeon.
Your mission is simple... but dangerous:

Escape the dungeon alive!

Along the way you must:

Navigate through a 5×5 dungeon grid

Collect shiny treasures 💎

Avoid deadly traps 💀

Fight scary monsters 👹

Protect your health ❤️

Increase your score ⭐

Find the final exit door 🚪

Every move counts. Every tile is a surprise

🕹️ Controls

W	Move Up

D	Move Right
Q	Quit Game
📦 How to Play
Option 1 — Play in Google Colab 

Upload dungeon_run.py into Colab

Run this command:%run dungeon_run.py
Option 2 — Play on Your Computer

Install Python 3

Save the file as:dungeon_run.py
Open terminal and run:python dungeon_run.py
